# Compressed E7 relative images and representation comparisons

Version 0.21 packages the [complete relative theorem](E7_ALL_PARABOLICS.md)
for all 127 proper standard parabolics of the simply connected E7 group,
and the trivial quotient G/G. Queries read a small installed data file;
they construct neither a Weyl group nor a Schubert matrix.

Version 0.22 adds the [analogous E6 interface](E6_RELATIVE_IMAGE_API.md),
preserving its separate factors 3,9,27. The E7 calls and coefficient
conventions below remain supported.

## Maps, lattices and conventions

Let X=X(T) be the weight lattice, Q the root lattice, and I the **retained
Levi nodes** in Bourbaki numbering. The edges are (1,3), (3,4), (2,4),
(4,5), (5,6), (6,7). The simple reflections indexed by I generate W_I.
Thus I=() gives G/B; I=(1,2,3,4,5,6) gives E7/P7; all seven nodes give G/G.
This retained-node argument differs from the omitted-node argument of
`BorelMap`.

For the rational Borel characteristic map beta, define the full integral
invariant-source images

\[
 M_I^d=\beta^{P_I}((\operatorname{Sym}_{\mathbb Z}^d Q)^{W_I}),
 \qquad N_I^d=\beta^{P_I}((\operatorname{Sym}_{\mathbb Z}^d X)^{W_I}).
\]

Polynomial degree d means cohomology degree 2d. Both images have the
cohomology rank n_I,d. The computer-assisted theorem gives

\[
 2N_I^d\subseteq M_I^d\subseteq N_I^d,\qquad
 N_I^d/M_I^d\simeq(\mathbb Z/2)^{m_{I,d}}.
\]

The local proofs at two determine this global integral relative quotient:
Q and X agree at odd primes. This is the quotient **of the two source
images**. It does not determine H^(2d)/N_I^d, their Schubert embeddings,
membership, polynomial preimages, or the algebra generated by mixed products.
Use the [embedded character API](MINUSCULE_CHARACTER_API.md) on E7/P7
when those actual image lattices are needed.

## Query any parabolic

```python
from sage_borel import exceptional_root_weight_comparison

p6 = exceptional_root_weight_comparison(
    "E7", retained_nodes=(1, 2, 3, 4, 5, 7))
assert p6.dimension == 42
assert p6.schubert_rank == 756
assert sum(p6.multiplicity_coefficients) == 366
row = p6.degree(2)
assert row.cohomological_degree == 4
assert row.multiplicity_2 == 1
assert row.relative_smith.torsion_multiplicities == {2: 1}
assert row.proof_family == "D5+A1"
```

The returned dataclasses and coefficient tuples are immutable.
`comparison.as_dict()` returns fresh JSON-safe lists and dictionaries,
including source conventions, proof references and the SHA256 of the
[canonical manifest](experiments/e7-all-parabolics-summary.json).
`degree(d).as_dict()` returns the degree, rank, relative Smith data,
source conventions and certificate provenance. A degree above the dimension has zero rank; negative,
nonintegral and boolean degrees are rejected. Repeated, boolean or
out-of-range nodes are rejected; node order is immaterial. The current
factory accepts the type strings `"E7"` and `"E6"`; use six-node retained
sets and the E6 guide's multiplicity dictionaries for E6.

`relative_smith.multiplicities` includes the n-m unit factors and m
factors equal to two. Its `rank` counts all n slots in the inclusion;
the finite quotient has `free_rank == 0`. `torsion_multiplicities` omits
units. Expansion and integer-index construction require explicit budgets
for large outputs:

```python
full = exceptional_root_weight_comparison("E7", retained_nodes=())
assert full.schubert_rank == 2903040
middle = full.degree(31).relative_smith
assert middle.rank > 100000
assert set(middle.multiplicities) <= {1, 2}
# middle.smith_factors() raises: the default expansion budget is 100000.
# middle.index(max_bits=10) raises before constructing a large integer.
small = p6.degree(2).relative_smith
assert small.torsion_factors() == (2,)
assert small.index() == 2
```

`smith_factors(max_rank=...)` expands all factors; `torsion_factors` expands
only nonunit factors. `index(max_bits=...)` computes the finite quotient's
order after a conservative bit bound. The compressed `as_dict()` never
expands factor lists or constructs the index. A unit factor is a trivial
cyclic summand, not a nonzero element of the quotient.

## Scaled root and weight sources

The degree-d images of Sym_Z(aQ) and Sym_Z(bX) are a^d M and b^d N,
for positive integer scales a,b. A simultaneous Smith basis of N puts M
in diagonal form with n-m entries 1 and m entries 2. For epsilon=0,1,
the two scaled diagonal entries are

\[
 A_\epsilon=a^d2^\epsilon,\qquad B_\epsilon=b^d.
\]

The sum and intersection have diagonal entries gcd(A,B) and lcm(A,B).
Consequently the quotients (sum)/left and (sum)/right have factors
A/gcd(A,B) and B/gcd(A,B). The quotients left/(intersection) and
right/(intersection) have factors B/gcd(A,B) and A/gcd(A,B), respectively.
These are elementary consequences of Smith normal form, not new image
theorems. The API returns the finite groups and containment flags, without
claiming an explicit simultaneous Schubert basis.

```python
scaled = p6.compare_scaled_sources(degree=2, root_scale=2, weight_scale=1)
assert scaled.left_in_right
assert not scaled.right_in_left
assert scaled.sum_mod_right.is_trivial
assert scaled.sum_mod_left.torsion_multiplicities[8] == 1
assert scaled.sum_mod_left == scaled.right_mod_intersection
```

The same method is available on a degree summary without the degree keyword.
All four quotient properties return compressed `RelativeSmithSummary` objects.
`diagonal_blocks` records (left entry, right entry, count) in an **abstract**
simultaneous basis. `same_rational_span` is always true, including zero images.
`equal` means both containment flags hold. These degreewise sums do not
include mixed products from different degrees.

## Minimal and adjoint Springer representations

Use the normalized trace Springer morphisms and the full polynomial-character
sources transported by inverse Springer pullback, as in the
[representation comparison](E7_REPRESENTATION_COMPARISON.md). The proved
degree-one source lattices are 12Q for the 56-dimensional minimal
representation and 36X for the 133-dimensional adjoint representation.
Their degree-d Borel images are therefore

\[
 \mathcal J_{56}^d=12^d M_I^d,\qquad
 \mathcal J_{133}^d=36^d N_I^d.
\]

In particular, for n=n_I,d and m=m_I,d,

\[
 (\mathcal J_{56}^d+\mathcal J_{133}^d)/\mathcal J_{56}^d
 \simeq(\mathbb Z/2)^m,\qquad
 (\mathcal J_{56}^d+\mathcal J_{133}^d)/\mathcal J_{133}^d
 \simeq(\mathbb Z/3^d)^n.
\]

The intersection quotients reverse these two groups. In positive degree
with n>0, the minimal image is never contained in the adjoint image; the
adjoint image lies in the minimal one exactly when m=0. When m>0 the
images are incomparable. In degree zero they agree; above the dimension
both are zero.

```python
p7 = exceptional_root_weight_comparison("E7", retained_nodes=range(1, 7))
c = p7.compare_representations(degree=1)  # left=minimal, right=adjoint
assert not c.left_in_right and not c.right_in_left
assert c.sum_mod_left.torsion_factors() == (2,)
assert c.sum_mod_right.torsion_factors() == (3,)
reverse = p7.degree(1).compare_representations(left="adjoint", right="minimal")
assert reverse.sum_mod_right == c.sum_mod_left
assert p7.compare_representations(degree=2).right_in_left
```

Only `"minimal"` and `"adjoint"` are named selectors here. Arbitrary scaled
root/weight sources use `compare_scaled_sources`. This API does not change
the supported parabolics of `e7_character_source`.

## Verification and provenance

[Packaging](tools/package_e7_relative_images.py) copies the canonical theorem
manifest reproducibly into [wheel data](src/sage_borel/data/e7_relative_images.json).
[Tests](tests/test_relative_images.py) reconstruct all cohomology polynomials
from Sage's independent Levi type/degrees calculation. They reconstruct
the 112 uniform multiplicity formulas, the twelve A5-family formulas via
Gaussian polynomial division, and the D6 closed formula. The two remaining
coefficient lists are compared against the separately audited native
D5+A1/D4+A1 image reports, with their hashes recorded in a
[test fixture](tests/data/e7_relative_audited_bases.json).

Scaling is checked against integer Smith/kernel computations on transformed
rank-three embedded lattices, including shared powers of two and odd prime
scales. Fresh E7/P7 character-image calculations in degrees 0,1,2,3,6,10
check both containment flags and all four quotients. This independently
checks arithmetic on overlapping cases; the source theorems and audited
base coefficient lists and the A5 intermediary polynomial T_0 remain shared
mathematical inputs. It does not
reprove every source-completeness theorem or establish literature priority.

The [API audit](relative-image-verification.json), full regression and
isolated-wheel checks are bound by the [current 0.22 release audit](release-0.22-verification.json).
The [0.21 record](release-0.21-verification.json) is the historical E7-only release.
Run from `borel/` in Sage:

```sh
PYTHONPATH=src sage -python tools/verify_relative_images.py
PYTHONPATH=src sage -python tools/verify_character_release.py
PYTHONPATH=src sage -python tools/verify_documentation.py
```
