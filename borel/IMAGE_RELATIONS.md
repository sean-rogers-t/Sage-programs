# Images and relations of chosen generators

Version 0.3 adds exact linear algebra for subalgebras generated by selected
Levi-invariant polynomials. It works with classical or exceptional Borel maps,
including general partial flags. All degree arguments are polynomial degrees:
degree `d` corresponds to cohomological degree `2*d`.

Version 0.4 also adds [complete kernel presentations](PRESENTATIONS.md):
`A.presentation()` computes a defining ideal, a standard monomial basis, and
an exact Hilbert series, with a certificate of completeness. The bounded
methods below remain useful when only a few degrees are needed.

In version 0.5, `A.presentation()` automatically uses a direct coinvariant
quotient for standard-numbered A/B/C/D. Explicit `backend="bgg"` selects the
original Schubert-coordinate calculation, and `P.verify(backend="bgg")` can
cross-check a coinvariant presentation on manageable examples. The degreewise
matrix methods below still return Schubert coordinates.

## A first example

```python
from sage_borel import BorelMap, GeneratorAlgebra

b = BorelMap("A2", omitted_nodes=1)  # projective plane
A = GeneratorAlgebra(b, {"h": b.weights[0]})

print(A.hilbert_function(4))         # (1, 1, 1, 0, 0)
print(A.first_relation_degree(4))    # 3
print(A.degree(3).relations)         # (h^3,)
```

The input dictionary names formal generators and supplies their polynomials in
fundamental weights. Each supplied polynomial must be nonzero, homogeneous, of
positive degree and Levi invariant. A nonzero polynomial is allowed to have zero
cohomology image. Algebraic independence of the chosen inputs is not assumed.

`A.domain` is a separate rational polynomial ring in the supplied names. Its
grading uses the degrees of their actual input polynomials, rather than assigning
degree one to every formal generator.

## Two-step symplectic flags

```python
from sage_borel import two_step_symplectic

F = two_step_symplectic(n=3, b=1, k=1)
A = F.joint_algebra()
c1, e1 = A.domain.gens()

print(F.omitted_nodes)              # (1, 2)
print(A.generator_degrees)          # (1, 2)
D = A.degree(4)
print(D.domain_dimension)           # 3
print(D.image_dimension)            # 2
print(D.kernel_dimension)           # 1
print(D.relations)                  # (c1^4 + c1^2*e1 + e1^2,)
assert not A.evaluate(c1**4 + c1**2*e1 + e1**2)
assert not A.evaluate(e1**3)
```

Here `a=n-b-k`, and the flag consists of isotropic subspaces of dimensions `a`
and `a+b` in a symplectic vector space of dimension `2*n`. The omitted nodes
are `(a,a+b)` and the Levi is `GL(a) x GL(b) x Sp(2k)`.

The selected generators are

$$
c_j=e_j(x_{a+1},\ldots,x_{a+b}),\qquad
e_i=e_i(x_{n-k+1}^2,\ldots,x_n^2),
$$

of polynomial degrees `j` and `2*i`, respectively. The first block grows while
the middle and tail factors remain fixed. `middle_generators`, `tail_generators`
and `joint_generators` return copies of the actual input dictionaries;
`middle_algebra`, `tail_algebra` and `joint_algebra` select the factor images to
analyze. Require `b,k >= 1` and `n >= b+k+1` for two genuine flag steps.

## What each report means

| API | Result |
| --- | --- |
| `A.monomials(d)` | Formal monomial basis of weighted degree `d` |
| `A.degree(d)` | Immutable exact image/kernel report |
| `D.matrix` or `D.coefficient_matrix` | Sparse QQ matrix, Schubert rows and monomial columns |
| `D.monomials`, `D.schubert_indices` | Exact labels for the matrix columns and rows |
| `D.image_dimension` or `D.rank` | Rank of the homogeneous map |
| `D.kernel_dimension`, `D.relations` | Dimension and a vector-space basis of the homogeneous kernel |
| `D.pivot_columns`, `D.image_basis_monomials` | Domain monomials whose images give an image basis |
| `A.degree(d, include_ambient=True)` | Also compute the complete degree-d Schubert basis dimension |
| `A.through_degree(D)` | Reports from degree zero through a finite bound |
| `A.hilbert_function(D)` | Image dimensions from zero through that bound |
| `A.first_relation_degree(D)` | First relation degree found through the bound, or `None` |
| `A.presentation()` | Certified complete kernel, quotient basis and Hilbert series |
| `A.substitute(p)` | Replace formal variables by the chosen Cartan polynomials |
| `A.evaluate(p)` | Compute the Schubert image of a formal polynomial |
| `D.as_dict()` | JSON-safe matrix, labels, relations and exact rational coefficients |
| `A.clear_cache()` | Release this algebra's computed matrices, powers and images |

The matrix stores only Schubert rows that occur in the selected images. Omitted
rows are zero and do not affect its rank or kernel. This avoids enumerating the
complete ambient basis. `include_ambient=True` obtains its dimension separately;
the stored matrix still uses the occurring support.

Relations in `D.relations` are a basis of a **single homogeneous kernel space**.
Computing several such spaces does not by itself certify generators of the entire
kernel ideal. Similarly, `None` from a bounded first-relation search means no
relation was found through that bound. It does not assert full injectivity.

## Uniform structure in the two-step family

The [invariant-theory derivation](experiments/TWO_STEP_DERIVATION.md) identifies the
joint kernel in this family with

$$
\bigl(h_{a+1}(Z),\ldots,h_n(Z)\bigr),\qquad
Z=\{x_{a+1}^2,\ldots,x_n^2\}.
$$

This is a consequence of the rational Borel presentation and elimination, with
no novelty claim. It provides a full ideal description for this specific family,
separate from the generic calculator's degreewise output.

The new generic `A.presentation()` independently recovers that full ideal by
constructing the selected image's entire monomial basis and checking its border.

`F.predicted_relations()` constructs these formal polynomials and
`F.predicted_hilbert_prefix(D)` calculates their presentation's Hilbert coefficients,
without using the computed Schubert matrices. These method names identify the
independent comparison used in the experiment, rather than an inference from
its measured ranks.

The [experiment script and recorded grid](experiments/README.md) compare the
Schubert calculations with that presentation for `b,k` in `{1,2}`. The
[independent verification record](algebra-verification.json) additionally checks
whole kernel spaces against Groebner reduction in coordinate coinvariant rings.
