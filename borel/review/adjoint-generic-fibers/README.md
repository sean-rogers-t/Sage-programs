## What is being claimed?

For a simple, simply connected complex algebraic group G, define theta_Ad
by B(theta_Ad(g),X)=tr(Ad(g)ad(X)), using the Killing form B. For every
proper Levi K, there is a dense open U_K in

    {h in z(k) : Z_G(h)=K}

such that the ACTUAL scheme theta_Ad^{-1}(h) intersect G_reg is smooth
for every h in U_K. Empty fibers and smooth positive-dimensional transverse
fibers are allowed. Regular nonsemisimple source points are included.

The proof is by classical families and exceptional cases. The main
review question is whether those arguments establish this exact statement,
without deleting a source locus that could dominate the central target.

## What does “certificate” mean?

It means exact, reproducible algebraic evidence for a particular step.
For example, to prove that r belongs to the ideal generated by g_1,...,g_m,
one could supply polynomials a_i with r=sum a_i g_i. Another person can
check that equality by expansion. That identity is a membership certificate.

Our E8 package contains two forms of evidence:

1. An explicit rational polynomial-combination identity in the written
   proof, with its terms reconstructed by the checker.
2. At each of two primes, 59 recorded polynomials whose membership is
   checked by replaying an exact ideal computation from the original
   generators. These records do NOT contain explicit multiplier vectors
   for every membership. The replay therefore depends on the correctness
   of the pinned algebra engine, as well as the checker and arithmetic.

The term does not mean that an outside mathematician has certified the
theorem, that the proof has been formalized in Lean, or that a saved
“passed” report is itself sufficient evidence. The written geometry and
the computation have different review obligations; see the
[certificate guide](CERTIFICATE_GUIDE.md).

## Reproduce the checks

Run these commands from the archive's `borel` directory, or from `borel`
in a checkout containing this review package. Linux/WSL is required for
the full engine replay. Python 3 and SymPy suffice for the native checks;
SageMath supplies its own algebra dependencies. Sage 9.5 was used for the
recorded calculations. No representation-theory API installation is needed.

First check the manifest, without executing symbolic algebra:

```sh
python3 review/adjoint-generic-fibers/run_review.py --mode integrity
```

Run the native coverage, polynomial-identity and monomial-degree audits:

```sh
python3 review/adjoint-generic-fibers/run_review.py --mode native
```

Build the pinned F4 engine. Here F4 is the name of a Groebner-basis
algorithm; it does not mean the exceptional group of type F4. The builder
needs Git, a C compiler, GMP/FLINT/MPFR development libraries, autoconf,
automake and libtool. It downloads the pinned msolve source and builds in
the user's cache; it does not install software globally.

```sh
bash tools/build_e8_last_certificate_engine.sh
python3 review/adjoint-generic-fibers/run_review.py --mode full \
  --engine "$HOME/.cache/sage-borel-e8-f4/e8-last-f4"
```

Full mode replays both primes, then performs the native checks. The
runner first checks the manifest and copies the inputs to a fresh temporary
directory. All regenerated reports and logs stay there, leaving the supplied
evidence unchanged. The output prints the directory and a compact result.
An optional `--output` must name a directory that does not yet exist.
The engine build location may be changed with `E8_F4_BUILD_DIR`.

Expected checks: 59 selected members at each of primes 32003 and 32009;
homogeneous dimension bound 4 and degree bound 21; accounted infinity
degree 21; affine Jacobian-deficiency dimension bound 2; 445 proper
E-type standard subsets and 136 cubic-subset transfers in the coverage
audit. Matching these numbers alone is insufficient: every identity,
membership replay and hash check must succeed.

Text hashes normalize CRLF to LF; compressed archives use raw-byte hashes.
Files in the archive are emitted with LF line endings so the shell builder
works on Linux. The package manifest is a reproducibility inventory, not
an additional mathematical certificate or a digital signature.

## Questions for an independent reviewer

- Does the regular adjoint quotient give the claimed actual-scheme
  presentation, including finite central descent and regular nonsemisimple
  points?
- Are the three sextics at infinity integral of degree six? Is the linear
  component's generic scheme multiplicity at least three?
- Is the direction of the homogeneous Hilbert-function comparison correct,
  and does the leading-monomial bound apply without claiming a complete
  Groebner basis?
- Does exhausting the top-dimensional degree at infinity imply the stated
  affine bound even in the presence of embedded components?
- Are the trace ramification loci excluded by proper TARGET loci, and is
  the bad-locus bound pulled back before using the original target map?
- Does the case dependency table cover every proper Levi without treating
  an abstract Dynkin-type match as a Weyl-conjugacy certificate?

Please distinguish an incorrect identity, a missing geometric hypothesis,
a reproducibility problem, and a possible prior-literature result. A
review finding should identify the exact statement or file and what would
be needed to repair it. No automatic “theorem proved” output substitutes
for this review.

## What remains outside the claim?

A uniform root-theoretic proof, a full nonemptiness/excess classification,
special targets, nonregular source components, generic map degrees, and
extensions to other representations remain separate questions. The final
E8 case does not establish generic nonemptiness. This package has been
prepared for review; it has not been sent to anyone.
